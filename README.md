# Book Management REST API

This project is part of my **Web Development Internship – Task 3**.  
It is a **REST API built using Node.js and Express** to manage a list of books with basic **CRUD operations**.  
No database is used; data is stored **in memory**.

---

## Objective

To understand and implement:
- REST API fundamentals
- Express.js routing
- HTTP methods (GET, POST, PUT, DELETE)
- JSON handling
- API testing using Postman

---

## Features

- Get all books
- Add a new book
- Update a book by ID
- Delete a book by ID
- Uses proper HTTP methods and status codes
- Tested using Postman

---

## Technologies Used

- **Node.js** – JavaScript runtime
- **Express.js** – Web framework for Node.js
- **Postman** – API testing tool
- **VS Code** – Code editor
